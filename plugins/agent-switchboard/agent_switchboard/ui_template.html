Agent Switchboard 使用说明

  1. 当前项目会把设置写入项目目录下的 .codex/config.toml；Codex 只加载受信任项目的设置。
  2. 全局设置写入用户目录的 config.toml。项目级设置会覆盖同一字段的全局值；清除此层覆盖后会重新继承。
  3. 默认子 Agent 使用此处选择的模型和推理强度；命名角色可单独设置。主 Agent 的模型、推理强度和速度在聊天框右下角调整。
  4. 模型列表来自本机 Codex 模型目录，推理档位随所选模型变化。标准会清除此配置层的快速模式；其他配置层仍可能启用快速模式。
  5. 空白表示继承，框内数字为当前值。上下文范围为 256,000 至所选模型上限；两项每次调整 10,000。修改上下文会按 Codex 建议更新压缩阈值，也可手动调整。
  6. 模型、推理强度和速度供后续请求读取；上下文和压缩阈值在新 Agent 启动时读取。上下文、压缩阈值和速度属于配置层共享设置，可能影响继承该层的其他 Agent。
  7. 预览窗口会列出写入位置、Agent 类型、修改前后值和注意事项；确认后才会写入配置。
