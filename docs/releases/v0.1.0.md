# Agent Switchboard 0.1.0 — Initial public release

Agent Switchboard adds a visual panel and natural-language tools for managing Codex agent settings. It works with Codex’s TOML configuration files and supports global and project scopes.

## Highlights

- Configure default subagent settings and named agent roles.
- Select supported models, reasoning levels, speed tiers, context windows, and compaction thresholds.
- Review validated changes and a diff before confirming a write.
- Preserve existing TOML comments and unrelated settings when applying changes.
- Keep operation history on the local machine.
- Install from the GitHub-backed marketplace.

## Install

```bash
codex plugin marketplace add xiajiadi/agent-switchboard
codex plugin add agent-switchboard@agent-switchboard-community
```

The plugin runs its MCP server locally and requires uv and Python 3.11 or newer. The repository includes the built UI bundle.

## Notes

Project-level settings are read by Codex only for trusted projects. Operation history can include local paths and values for settings managed by the plugin. Review [PRIVACY.md](../../PRIVACY.md) before sharing logs.
